# 简历自动填充助手（Chrome MV3）

在折叠式表单中手动维护网申档案，可保存到本地或导入导出表单 JSON，并使用 AI 匹配填充当前招聘页面。插件不会自动提交表单。

## 使用

1. Chrome 打开 `chrome://extensions`，开启“开发者模式”并选择“加载已解压的扩展程序”。
2. 选择本目录，然后打开插件侧边栏。
3. 展开“手动填写网申资料”；教育、实习/工作、项目、干部、语言证书和获奖经历均可新增或删除多条。
4. 填写后保存；也可导出表单 JSON，供下次导入恢复。
5. 打开招聘网站的申请表单，点击“AI 匹配填充”。
6. 人工检查下拉框、日期、经历和必填项后自行提交。

更新代码后，需要在 `chrome://extensions` 中重新加载插件；下次填充会热注入当前脚本，无需刷新已有内容的目标网页。

侧栏打开后，当前表单右下角会出现“简历助手：填充当前页面”。该按钮打开对应侧栏并复用 AI 填充流程，展开“填充诊断”可查看脱敏结果；本地代理重启后会从已保存配置重新连接。

## 数据与边界

- 本地数据使用 `chrome.storage.local` 保存，导出文件为可读 JSON。
- 兼容导入本功能导出的表单 JSON，以及旧版结构化 `profile` JSON。
- 通过 `label`、`aria-label/aria-labelledby`、placeholder、name、id、所属模块和重复项序号识别字段，不绑定单一招聘站点。
- 支持原生输入/下拉/单选/日期及已验证的自定义控件结构；可扫描没有 ARIA、带 tabindex=0 和 select 类名的自定义下拉，并复用实时候选与回读。其他无语义 div/button 仍可能漏扫；React、Vue 或组件库名称本身不代表兼容。不会自动提交。
- AI 补充选择框时，会实时打开控件读取页面候选项；滚动式或惰性渲染的弹层会有限滚动采样候选。AI 优先返回原样候选；若简历值与页面候选只有唯一的包含式规范化匹配，客户端会规范化为该页面原始选项。对级联控件会在父项选中后再读取一次子项候选；候选缺失、歧义或低置信度时保持为空。
- 支持月份选择器：可用前后按钮切换年份，也可点击年份标题或已显示的年份候选，再选择月份；没有日历类名或日期表格时，通过实际月份候选识别已打开的年月弹层。聚焦已打开弹层时不重复点击，优先读取新弹层并兼容上下方定位；关闭时先通过 Tab 结束编辑，再失焦、关闭弹层。首次聚焦缓存异常年份列表时重新打开并读取，候选仍异常则跳过。支持“添加经历”这类带 `_addButton` 标识的普通元素，不要求它必须是 `button`。
- 年月弹层切换年份后等待标题确认，再读取新的月份节点；跳过禁用月份，并扫描由父级 picker 提供语义的只读输入框。
- 同一经历中的名称选择框会等待前置类型/类别选择框确认，随后重新读取候选；编号卡片归入同一模块。获奖类型使用该条奖项名称或显式类型作为来源，奖项说明不再作为名称锚点。AI 可匹配同一赛事的别名，并参考该条获奖级别；奖项名称没有对应候选时可选页面提供的“其他”，具体名称和说明仍保留本地原文。目标职位类别允许 AI 根据期望职业匹配页面提供的上位职能类别，来源仅限职业意向。
- 已有页面值默认保留；重复经历只补充缺少的行，不删除页面原有行。
- 工作/实习按同一重复行判断：有独立工作业绩或亮点字段时分开填；没有时在职责框合并工作内容与业绩，“职责：”和“亮点：”各占一行，正文从下一行开始，空段省略。
- 原生数值框写入前校验数字格式及页面 min/max/step；独立数值 GPA 可从“绩点 / 排名”的明确复合格式取绩点，排名仍单独匹配，普通文本保留原文。
- 教育经历可单独保存成绩排名；项目描述仅按明确职责标题拆分，已有独立职责时保留完整描述及链接，失焦后截短的正文不计确认成功。
- 教育经历可单独保存 GPA 类型（满分制）；GPA 成绩只保存绩点。兼容明确的“绩点 / 满分”输入，分别填入成绩和页面提供的满分制候选，分母不会用作排名；纯绩点不能推断类型。满分制未确认或与页面已有类型冲突时跳过空成绩。
- 基本信息中的最高学历学校、专业和毕业日期来自唯一的最高学历教育记录；同级记录并列时跳过，学校和专业仍须确认页面候选。
- 当页面没有独立“实习经历”模块时，会按手动表单原顺序把实习和工作经历一起填入“工作经历”，避免实习条目被过滤掉。
- 表单位于 iframe 时，会轮询动态 frame，并优先选择包含招聘字段语义的 frame。
- 新站点需分别确认扫描、模块/重复行归属、语义匹配、页面候选、控件交互及失焦/重渲染回读。增加 `FIELD_ALIASES` 或 `SECTION_ALIASES` 只解决文案匹配；不能补救漏扫或页面不接受写入。缺少本地来源或候选不明确时跳过；控件兼容修复须依据真实页面证据。
- `docs/通用招聘表单智能识别可行性调研.md` 是设计与调研记录，不是全部方案已实现或所有招聘网站已验收的证明。mock 通过只覆盖对应模拟结构；百度等实际页面未完成回读时仍属未验收。
- 不处理验证码、登录、二次验证和封闭 Shadow DOM。

## AI 配置

需要 Node.js 18+。先启动本地代理：

```powershell
node .\resume-autofill\ai-proxy\server.js
```

在侧边栏填写 API Key、Base URL 和模型名，点击“保存配置并连接”。配置只保存在本机。
