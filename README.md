# 简历自动填充助手（Chrome MV3）

在折叠式表单中手动维护网申档案，可保存到本地或导入导出表单 JSON，并使用 AI 匹配填充当前招聘页面。插件不会自动提交表单。

## 使用

1. Chrome 打开 `chrome://extensions`，开启“开发者模式”并选择“加载已解压的扩展程序”。
2. 选择本目录，然后打开插件侧边栏。
3. 展开“手动填写网申资料”；教育、实习/工作、项目、干部、语言证书和获奖经历均可新增或删除多条。
4. 填写后保存；也可导出表单 JSON，供下次导入恢复。
5. 打开招聘网站的申请表单，点击“AI 匹配填充”。
6. 人工检查下拉框、日期、经历和必填项后自行提交。

更新代码后，需要在 `chrome://extensions` 中重新加载插件；下次填充会热注入当前脚本，无需刷新已有内容的目标网页。

侧栏打开后，当前表单右下角会出现“简历助手：填充当前页面”。该按钮打开对应侧栏并复用 AI 填充流程，展开“填充诊断”可查看脱敏结果；本地代理重启后会从已保存配置重新连接。

- 原生数值框写入前校验数字格式及页面 min/max/step；独立数值 GPA 可从“绩点 / 排名”的明确复合格式取绩点，排名仍单独匹配，普通文本保留原文。
- 教育经历可单独保存成绩排名；项目描述仅按明确职责标题拆分，已有独立职责时保留完整描述及链接，失焦后截短的正文不计确认成功。
- 教育经历可单独保存 GPA 类型（满分制）；GPA 成绩只保存绩点。兼容明确的“绩点 / 满分”输入，分别填入成绩和页面提供的满分制候选，分母不会用作排名；纯绩点不能推断类型。满分制未确认或与页面已有类型冲突时跳过空成绩。
- 基本信息中的最高学历学校、专业和毕业日期来自唯一的最高学历教育记录；同级记录并列时跳过，学校和专业仍须确认页面候选。
- 当页面没有独立“实习经历”模块时，会按手动表单原顺序把实习和工作经历一起填入“工作经历”，避免实习条目被过滤掉。
- 表单位于 iframe 时，会轮询动态 frame，并优先选择包含招聘字段语义的 frame。
- 新站点需分别确认扫描、模块/重复行归属、语义匹配、页面候选、控件交互及失焦/重渲染回读。增加 `FIELD_ALIASES` 或 `SECTION_ALIASES` 只解决文案匹配；不能补救漏扫或页面不接受写入。缺少本地来源或候选不明确时跳过；控件兼容修复须依据真实页面证据。
- `docs/通用招聘表单智能识别可行性调研.md` 是设计与调研记录，不是全部方案已实现或所有招聘网站已验收的证明。mock 通过只覆盖对应模拟结构；百度等实际页面未完成回读时仍属未验收。
- 不处理验证码、登录、二次验证和封闭 Shadow DOM。
